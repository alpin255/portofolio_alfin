Sistem E-Pelanggaran SMK

Dokumentasi arsitektur REST API backend Laravel dan Single Page Application Vue 3 untuk SMKN 1 Rejotangan.

Kriteria Bobot Poin Pelanggaran

Setiap pelanggaran memiliki ambang batas yang secara otomatis memicu dispatch event pembuatan dokumen PDF:

  • ✓ Akumulasi ≥ 15 poin: Pembinaan Konseling Wali Kelas
  • ✓ Akumulasi ≥ 30 poin: Terbit Surat Peringatan 1 (SP-1)
  • ✓ Akumulasi ≥ 50 poin: Pemanggilan Orang Tua ke Sekolah

Testing & Eksekusi

Endpoint dapat diuji melalui Postman collection yang disertakan dalam folder tests/api/.
