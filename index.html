STATUS PROFESIONAL Tersedia untuk Magang / Kontrak / Proyek Web

Latar belakang saya bukanlah jalur konvensional lulusan komputer murni sejak awal. Semasa menempuh pendidikan kejuruan di SMKN 1 Rejotangan dengan jurusan Teknik Kendaraan Ringan (TKR), hari-hari saya dihabiskan bergelut dengan mesin mobil, sistem pengapian, dan perkakas bengkel.

Di sela-sela rutinitas praktikum kejuruan otomotif tersebut, ketertarikan saya pada logika sistem membawa saya secara mandiri dan tekun mendalami dunia rekayasa perangkat lunak dan pemrograman web. Pola pikir mekanik otomotif yang terbiasa dengan root cause analysis (mencari sumber gangguan mesin sampai ke komponen terdalam) ternyata menjadi bekal paling berharga saat mendebug kode yang kompleks.

Kini di bangku kuliah Universitas Bhinneka PGRI Tulungagung, kombinasi ketajaman analisis praktis dan fondasi teoritis ilmu komputer menghasilkan solusi nyata: mulai dari digitalisasi sistem kesiswaan E-Pelanggaran di SMKN 1 Rejotangan menggunakan Laravel & Vue 3, hingga sistem Kasir POS Toko Kelontong berbasis Java yang beroperasi nyata di Rejotangan.

Digitalisasi pencatatan kedisiplinan dan pelacakan akumulasi poin pelanggaran siswa berbasis web. Menggantikan proses manual buku kertas konvensional dengan sistem basis data terpusat, transparan, dan terukur.

MASALAH & KONTEKS

Pencatatan pelanggaran siswa sebelumnya dikerjakan manual di buku fisik BK. Data rekap poin sering terlambat dihitung, arsip rawan hilang, dan penyusunan Surat Panggilan (SP) memakan waktu [ISI: durasi rekap manual sebelumnya, mis. 2-3 hari kerja] serta membebani staf kesiswaan.

PERAN SAYA

Fullstack Developer (Inisiator & Pengembang Magang). Merancang skema relasi basis data MySQL, mengimplementasikan RESTful API dengan Laravel, membangun Single Page Application dengan Vue 3 Composition API, dan mengintegrasikan template cetak PDF resmi.

KEPUTUSAN TEKNIS

Pemisahan arsitektur REST API dengan frontend SPA untuk respon kilat tanpa reload halaman di ruang BK. Menggunakan Role-Based Access Control (RBAC) dengan pemisahan wewenang ketat (Kesiswaan, Guru BK, Wali Kelas) dan kalkulasi poin otomatis dengan database transaction guna mencegah *race condition*.

Sistem Kasir POS Toko Kelontong

Aplikasi Point of Sale desktop mandiri (*standalone*) berbasis Java dan MySQL untuk mendigitalkan kasir pertokoan kelontong di Rejotangan. Dirancang dengan keandalan operasional tinggi, tahan pemadaman koneksi internet, dan terintegrasi perangkat keras kasir.

MASALAH & KONTEKS

Pemilik toko kelontong di area Rejotangan mengandalkan catatan buku manual atau kalkulator. Kasir kewalahan saat antrean ramai, perhitungan harga grosir sering salah hitung, dan aplikasi kasir berbasis web/cloud sering mandek ketika jaringan internet seluler desa tidak stabil.

PERAN SAYA

Solo Desktop Application Developer & Hardware Integrator. Mengembangkan sistem secara menyeluruh dari perancangan OOP, konektivitas JDBC ke database MySQL lokal, hingga integrasi I/O port printer thermal dan pengujian langsung di meja kasir toko.

KEPUTUSAN TEKNIS

Arsitektur *Offline-First* murni tanpa ketergantungan cloud server. Komunikasi printer struk menggunakan stream protokol ESC/POS langsung lewat port USB/Serial, integrasi event listener keyboard untuk scanner barcode tanpa delay, serta otomasi sinyal pembuka laci uang tunai (*cash drawer kick-out*).

• [ISI: Waktu rata-rata cetak struk dan checkout transaksi, mis. < 15 detik per transaksi]
• 100% ketersediaan operasional tanpa pernah terganggu oleh gangguan sinyal internet.
